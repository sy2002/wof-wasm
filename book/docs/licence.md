# The licence and the game data

The repository and this book hold two kinds of thing: the project's own work, which anyone may copy and change under one of two licences, and the game itself, which is under neither and is kept for preservation. This page says what the repository's [`README.md`](repo:README.md#licence) says in its section "Licence", and for the book what the book's handbook, [`book/BOOK.md`](repo:book/BOOK.md), adds.

## The code and the tools

The code and the tools of the repository, [`src/`](repo:src/), [`web/`](repo:web/), [`tools/`](repo:tools/), [`tests/`](repo:tests/) and the build, are free software under the GNU General Public License, version 3 or later, in [`LICENSE`](repo:LICENSE). The licence's preamble says what it asks of whoever passes copies on: to pass on the same freedoms they received, so that the recipients also receive the source code or can get it, and are shown these terms.

## The prose

The prose, the specification [`SPEC.md`](repo:SPEC.md), the notes in [`re/notes/`](repo:re/notes/) and this book in [`book/`](repo:book/), is under Creative Commons Attribution-ShareAlike 4.0 International, in [`LICENSE-CC-BY-SA-4.0`](repo:LICENSE-CC-BY-SA-4.0). The licence's own summary asks whoever shares or adapts it to give appropriate credit, link the licence and indicate what was changed, and to distribute what they build on it under the same licence.

## The game

The game's data is covered by neither licence. That is everything under [`original/`](repo:original/), the disk image, the files extracted from it and the manual's text; the two listings, [`re/Wings.lst`](repo:re/Wings.lst) and [`re/songplay.lst`](repo:re/songplay.lst), which reproduce the executable's code; the contact sheets in [`ref/sheets/`](repo:ref/sheets/); and the game data inside the page, [`dist/wof.html`](repo:dist/wof.html).

In this book the same holds for the figures rendered from the game's data, for the listings taken from its executable, and for the game the site embeds, which is that page.

Wings of Fury is the work of its authors and its publisher, Broderbund, 1990. It is kept here for preservation, and no right to it is granted.

## The ROM

The [Kickstart](glossary.md#kickstart) ROM, the Amiga's own system, from which the build takes the system font and the key table ([chapter 1](part-1/faithful.md#one-file-in-the-browser)), is not in the repository at all: whoever builds the port places their own copy, as [chapter 25](part-3/build.md#the-rom) shows.

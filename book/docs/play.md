Click into the game once, so that the keyboard goes to it. The key H shows the keys and F switches to fullscreen; the help screen is up when the game starts, and any key starts the sound and the game. [The game alone, in its own tab.](play/wof.html)
{ .wof-game-note }

This is the repository's own page, `dist/wof.html`: the game built from the port's sources into one HTML file, and copied into this site unchanged every time the site is built. It loads nothing from anywhere and keeps its saved games and settings in the browser.

The port's code is free software, but the game's data inside the page is not: the pictures, sounds, music and texts of Wings of Fury belong to its authors and publisher, Broderbund (1990), and are kept here for preservation without any right to them being granted.
